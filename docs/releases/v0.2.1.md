# Kepenk v0.2.1

**Release date:** 2026-07-31

Kepenk v0.2.1 is a focused portability patch for the composite GitHub Action.

## Fixed

The Action no longer configures `actions/setup-python` with consumer-repository pip caching. In v0.2.0, that cache setting caused setup-python to fail before policy evaluation when the target repository had no `requirements.txt`, `pyproject.toml`, or another Python dependency file.

The failure was reproduced by the public Ustaca AI npm/Turborepo founding-team pilot and fixed without requiring the consumer repository to become a Python project.

## Compatibility

The following remain compatible with v0.2.0:

- Action inputs and defaults;
- outputs `valid`, `effect`, `rule_id`, `reason`, and `rule_count`;
- decision exit codes `0`, `64`, `75`, and `77`;
- pinned `actions/setup-python` revision and Python 3.11 runtime;
- local installation from the checked-out Action directory;
- policy format and all package interfaces.

## Verification

The maintenance source is based on `v0.2.0` and contains no v0.3 feature work. CI verifies:

- Ubuntu and Windows on Python 3.11 and 3.13;
- Ruff and strict mypy;
- the complete v0.2 test suite;
- Action portability configuration;
- policy examples, demonstrations, and pre-commit behavior;
- clean wheel and source-distribution installs;
- all three public command entry points.

The public pilot must also pass after pinning the released `v0.2.1` tag.

## Security boundary

Kepenk remains a policy and approval layer rather than a sandbox. This patch changes only Action setup portability; it does not broaden permissions or execute proposed actions.

## Installation

```bash
python -m pip install "https://github.com/bilgi-ship-it/kepenk/archive/refs/tags/v0.2.1.zip"
```

GitHub Actions:

```yaml
- uses: bilgi-ship-it/kepenk@v0.2.1
  with:
    mode: validate
    policy: kepenk.yaml
```

Public PyPI publication remains separate and is not performed by this GitHub Release process.
